⚽ יומן משחקי ליגת העל (WINNER) — עונת 2026/27

מתעדכן אוטומטית כל שעה מהאתר הרשמי של ההתאחדות לכדורגל בישראל.

כתובת ההרשמה ליומן (ICS): https://yiznagar.github.io/ligat-haal-calendar/league.ics
Outlook (דפדפן): Subscribe from web
  1. היכנס ל־outlook.office.com/calendar (או outlook.live.com).
  2. בסרגל הצד: Add calendar → Subscribe from web.
  3. הדבק את הכתובת שלמעלה, תן שם ליומן (למשל “ליגת העל”), ואשר.
  4. Outlook ירענן את היומן מעצמו כל כמה שעות.

Google Calendar: “יומנים אחרים” → “מכתובת URL” → הדבק את אותה כתובת.
Apple Calendar: File → New Calendar Subscription → הדבק את הכתובת.

כל משחק מקבל מזהה קבוע (UID) לפי מספר המשחק באתר ההתאחדות, כך ששינוי תאריך, שעה או אצטדיון מעדכן את האירוע הקיים ולא יוצר כפילות.  •  הורדת league.ics
